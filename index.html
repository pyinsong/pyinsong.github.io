🤖 ML & Predictive Modeling

End-to-end model builder — from raw bureau trade-line data and alternative FCRA credit data through feature engineering, training, evaluation, and production deployment via DataRobot. Primary focus on classification models for credit underwriting, marketing response, propensity, and conversion use cases.

XGBoost LightGBM Logistic Regression LSTM (Keras) scikit-learn SHAP DataRobot Propensity Modeling Uplift Modeling Customer Segmentation
  • Information Value (IV) & Weight of Evidence (WoE) — industry-standard scorecard binning; IV > 0.3 signals strong predictive power · de facto standard in credit card DS
  • Tree-based importance + SHAP — global feature ranking via gain/split count; SHAP for per-prediction attribution and feature culling
  • Recursive Feature Elimination (RFE) — wrapper method with cross-validated performance as stopping criterion
  • Variance Inflation Factor (VIF) — multicollinearity detection; drop features with VIF > 10 before logistic models
  • Monotonicity constraints — enforce directionally sensible relationships for regulatory and explainability compliance
  • Population Stability Index (PSI) on features — flag features drifting between train and scoring windows before they degrade the model
  • KS Statistic — primary separation metric in credit card modeling; measures max distance between cumulative good/bad distributions across score bins
  • AUC-ROC & Gini coefficient — Gini = 2×AUC − 1; threshold-independent rank-ordering performance
  • Lift curves & decile / gains analysis — "top 2 deciles capture X% of responders" — the language of marketing campaign targeting decisions
  • Calibration & reliability diagrams — ensures predicted probabilities are well-calibrated when used as continuous scores for cutoff optimization
  • PSI for model stability monitoring — tracks score distribution shift between development and production populations over time
  • Precision / Recall / F1 & log loss — used for threshold selection and probabilistic model comparison
  • Hypothesis framing — null / alternative hypothesis, one-tailed vs. two-tailed tests; Type I (false positive, α) and Type II (false negative, β) error trade-offs
  • Sample size & power calculation — pre-experiment sizing using effect size, α, and target power (1−β); prevents underpowered tests that produce inconclusive results
  • p-value vs. confidence interval interpretation — CI-first reporting avoids binary pass/fail thinking; quantifies magnitude and uncertainty of lift
  • Multiple testing correction — Bonferroni for conservative control; Benjamini-Hochberg (FDR) when testing many segments simultaneously
  • Stratified & matched randomization — pre-stratify on key covariates (risk tier, channel, vintage) to reduce variance and prevent imbalanced test/control splits
  • Holdout group design — permanent holdouts for long-running champion-challenger model evaluation; distinguishes model lift from campaign lift
  • Incremental lift measurement — isolates treatment effect from organic behavior; bridges A/B testing into uplift modeling for targeting persuadables only
  • Sequential testing & early stopping rules — alpha-spending functions (O'Brien-Fleming) to allow interim looks without inflating Type I error

📁 Ballistic Trajectory Solver

Physics-based long-range ballistic calculator built from first principles. Solves the 6-DOF point-mass ODE using RK4 / scipy.integrate.solve_ivp, incorporating G7 drag models, atmospheric correction (temperature, altitude, humidity), spin drift, and Coriolis effects. Results validated against JBM Ballistics reference tables. Outputs scope adjustments in MOA and MIL via an interactive Plotly Dash web app.
